# 🚀 AWS AppSec CI/CD Lab

A hands-on Application Security (AppSec) project focused on building a secure CI/CD pipeline on AWS using open-source security tools.

---

## 📖 Overview

This repository demonstrates how to integrate security throughout the Software Development Lifecycle (SDLC) by building a CI/CD pipeline that automates code analysis, security testing, and deployment.

The project is designed to provide practical experience with Application Security engineering, CI/CD, cloud deployment, and security automation.

## 🎯 Learning Objectives

- Build a CI/CD pipeline using Jenkins
- Deploy a web application to Amazon S3
- Automate deployments from GitHub
- Integrate open-source security tools into the pipeline
- Understand Secure Software Development Lifecycle (SSDLC)
- Implement security gates before deployment
